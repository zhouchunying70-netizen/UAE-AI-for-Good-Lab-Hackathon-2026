# Public Knowledge-Base Boundary

This release contains 12 source records, 8 admitted claims, and 7 supporting
UAE sources represented by metadata, recorded internal hashes, scoped
paraphrases and official URLs. Runtime retrieval is exact metadata/tag-based;
this is not vector retrieval, semantic ranking or an ITU-Lab-hosted distributed
knowledge base. Raw policy and standards files are excluded. Runtime and
verifier output must report
`RAW_SOURCE_VERIFICATION_NOT_PERFORMED_IN_PUBLIC_BUNDLE`. A recorded hash is
not a substitute for source-byte verification, legal review, policy
completeness or redistribution permission. The remaining 5 registered records
are retained as metadata-only or standards/reference records and are not
counted as supporting UAE claims. `retrieval-index.json` is a derived tag index; it is not an embedding index and does not imply vector retrieval.
